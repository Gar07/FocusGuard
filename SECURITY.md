# Kebijakan Keamanan (Security Policy)

Keamanan aplikasi **FocusGuard** dan integritas perangkat pengguna adalah prioritas penting bagi kami.

## Versi yang Didukung

Pembaruan keamanan aktif disediakan untuk versi rilis berikut:

| Versi | Didukung Secara Aktif |
| :--- | :--- |
| `v1.0.x` | :white_check_mark: Ya |
| `< 1.0.0` | :x: Tidak |

---

## Melaporkan Kerentanan Keamanan (Reporting a Vulnerability)

Jika Anda menemukan celah keamanan (*security vulnerability*) atau bug bypass autentikasi PIN pada FocusGuard, mohon untuk **tidak** melaporkannya melalui GitHub Issues publik demi melindungi pengguna yang sedang memasang aplikasi.

Harap laporkan temuan Anda secara privat melalui salah satu cara berikut:
1. **GitHub Security Advisory:** Masuk ke tab [Security Advisories](https://github.com/Gar07/FocusGuard/security/advisories/new) di repository GitHub kami untuk membuat laporan rahasia.
2. **Kontak Pengelola:** Hubungi pemilik repository [@Gar07](https://github.com/Gar07) secara langsung.

### Informasi yang Dibutuhkan dalam Laporan
* Deskripsi kerentanan dan potensi dampaknya (misalnya: cara mematikan sirine sentry tanpa memasukkan PIN).
* Langkah-langkah detail untuk mereproduksi masalah (*proof of concept*).
* Versi Android dan perangkat keras/emulator yang digunakan untuk pengujian.
* Saran mitigasi atau perbaikan (jika ada).

### Waktu Tanggapan (SLA)
* **Konfirmasi Penerimaan:** Dalam waktu maksimal 48 jam kerja.
* **Verifikasi & Investigasi:** Dalam waktu 3–5 hari kerja.
* **Perilisan Patch Perbaikan:** Segera setelah perbaikan diverifikasi dan lolos pengujian unit.

Terima kasih telah membantu menjaga keamanan ekosistem FocusGuard!
